# ブランドと言葉の原則

## 読み手と役割

LP は、親自身も子どもと発見を楽しむ場面を描く。写真から調べ、自分たちの図鑑をつくる体験につなげる。中心価値は [product-principles.md](product-principles.md) に従う。

操作・登録・設定の案内は親に向け、漢字を使った自然で簡潔な日本語にする。図鑑の本文や観察の問いかけは、親が子どもへ読み聞かせられる短文にする。画面単位で幼児向けの口調に揃えず、文章の役割ごとに判断する。

親や子どもの能力を評価する言葉は避け、発見したことや一緒に楽しむ行為を受け止める。問いかけは安全に見て気づける特徴や、親子で話せる経験を扱う。

## 用語の意味

- 図鑑は写真と調べた内容が集まる場所。親向けの表記は「図鑑」に揃え、読み聞かせ本文では「ずかん」も使う。
- 発見は見つけたものや体験、写真は選択・送信・表示する画像、記録は削除など保存データを正確に示す場合に使う。
- 調べる、保存する、状態を確認する、もう一度調べるを区別する。ボタンは実際に行う操作を示す。
- 装飾のためだけの英語見出しは増やさない。対象の英語名や発音など、意味のある英語は残す。

## 状態と期待

エラーでは状態、保存の有無、次に取れる行動を伝える。保存結果が不明な写真を未保存と断定せず、保存済みなら写真を選び直す案内をしない。取り消しや再実行を説明するときは、その状態で可能な操作と揃える。

一緒につくる体験は、親子で発見し写真を選び同じ図鑑を楽しむこと。共同編集、会話の自動記録、冊子配送など、実装されていない機能への期待を生む表現は加えない。

## 適用範囲

LP、アプリの表示、ページタイトル、読み上げラベル、印刷物、AI の新規生成文へ同じ基準を適用する。機能名を変える場合は入口と遷移先を揃える。AI の生成方針を変えても、既存の記録を一括で書き換えない。

個別のコピー一覧はここに複製しない。表示文言の一次ソースは React コンポーネント、生成指示は `app/Services/ImageAnalysisService.php` とする。
